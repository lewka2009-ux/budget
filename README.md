# Семейный бюджет

Веб-приложение (PWA) для учёта трат, бюджета, целей и капитала семьи.
Данные хранятся не здесь, а в личной Google Таблице владельца: приложение подключается к ней
через Google Apps Script по ключу доступа. В этом репозитории нет никаких личных данных.

Установка на телефон: открыть сайт → «Поделиться» → «На экран Домой» (iPhone) или меню ⋮ → «Добавить на главный экран» (Android).
